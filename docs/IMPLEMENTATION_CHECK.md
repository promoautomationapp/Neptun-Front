The comparison covered 367 original named exports and every original stylesheet. Renamed/split helpers were checked against their current equivalents: CoverThumbnail → CampaignCoverThumbnail, repairCoverProductPlacements → repairCoverProductLayout, inspectPreparedImage → image-inspection, screenAnnotationPlacement → screenAnnotationGeometry, and the cutout revision → backend provider metadata. Classic editor code is retained in `features/classic`; its sidebar shortcut is hidden as requested.

Validation after these changes: clean locked dependencies passed the frontend production build, 484 tests in 101 files, and Wrangler deployment dry run. Backend build and 221 tests in 41 suites passed against the isolated test database. Representative UI checks covered login at 1280×720 and 390×844 with no page overflow; campaign dialogs kept close/final actions visible at both sizes. Settings keeps Save visible, scrolls long option panes, preserves full preview proportions and offers an enlarged preview. These checks do not claim that every possible device/state has been visually inspected.

The catalog filter bar now has one stable full-depth category picker, shared with the brochure product picker, plus searchable brand/availability controls. Selection through four levels keeps all three filter rectangles unchanged. Text search and code-only search ignore case and spacing. The complete product index loads in at most four concurrent page requests and rejects incomplete/changed snapshots instead of silently replacing the index. Source categories load independently of the product index, including empty branches. Read-only comparison of Neptun’s homepage menu against stored source categories found matching 213 unique paths (216 category URL entries), 13 roots and a maximum depth of four. All 4,589 saved catalog products remain present; absence from the website is metadata, not deletion. Some source detail pages return HTTP 403; saved details remain available and the scheduled/manual refresh can retry them.

The backend changes are pushed as 246e52c and 8474f39. Live authenticated checks confirmed the new source-category response (216 entries) and fast media responses while the bounded R2 inventory runs separately. R2 verification completed with 32,801 objects and 1,043,840,026 bytes, exactly matching the registered asset totals. No AI jobs, catalog refreshes, invitations or emails were created for QA.

AI usage now has overview/charts, operation/model breakdown and detailed-record tabs, preserving unknown and partial charges explicitly. Responsive table wrappers and searchable filters remain available throughout. Sidebar account/profile and sign-out actions are separated; support identity privacy is unchanged. Brochures show Expired after the final day in Europe/Belgrade, including already-open tabs, without deleting the brochure or changing review history. Photo cover is no longer selectable; old saved photo covers still render. Built-in presets are code-authored logo-free backgrounds, with independent editable logos; uploaded images retain their pixels.

Frontend changes after 4f47a9b remain in the local checkout for the user’s commit/push. Test preview pages are isolated sample-data fixtures under ignored artifacts/ and are not part of the deployed application.
